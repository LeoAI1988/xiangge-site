## 推荐技术架构

第一阶段：

- 静态页面：Nginx 直接托管。
- 领取登记：后端提供 `POST /api/leads`，保存到 SQLite。
- 管理后台：查看、导出 CSV、标记是否已发放赠品。
- 资源链接：后台配置网盘码、PDF 链接、Skill 下载链接。

第二阶段：

- 购买跳转：正课跳转小鹅通或微信小店。
- 手机号匹配：用户在本站登记的手机号和小鹅通/微信小店购买手机号打通。
- 赠品权限：登记用户看前 10 节申请入口，付费用户看完整赠品入口。

第三阶段：

- PDF：确认授权和清理处理后，可放腾讯 COS 或服务器下载目录。
- 视频：不要放服务器，建议放小鹅通、微信小店、网盘或专业视频托管。
- Skill：放对象存储或服务器下载目录，后台按登记状态展示下载权限。
