# 岩井俊二风格 · AI 情感短剧 Skill

## 一、用途

生成 50 秒以内的情感短剧剧本，复刻岩井俊二克制美学，击中人性底层共鸣，适用于：
- 视频号 / 抖音 / 小红书
- 35-55 岁主力 + 18-25 岁年轻群体的双重覆盖
- 高完播率 + 高转发率的内容生产

**核心美学：** 慢动作 + 静默 + 日常细节放大 + 未说出口 + 逆光过曝 + 留白

## 二、适用边界（重要）

**本 skill 只处理"岩井俊二克制情感"路线。** 以下类型不复用：

| 任务类型 | 不适用原因 | 应该走 |
|---------|-----------|--------|
| 游戏化/转场风格（UI+地图+血槽） | 核心是视觉冲击，不是情感克制 | 通用剧本工作流 |
| 动作/特效向（爆炸/打斗/科幻） | 与慢镜头+静默反向 | 普通分镜表 |
| 10-15 秒短剧 | 本 skill 默认 50 秒结构 | 紧凑运镜 + 色温变化模板 |
| 快切/多镜头剪接 | 岩井偏好长镜头不切 | 每秒 1-2 镜的分镜表 |

**判别三问（写剧本前必答）：**
1. 核心是"情感克制"还是"视觉冲击"？→ 视觉冲击 = 不调用
2. 时长是 50 秒 还是 10-15 秒？→ 短时长 = 不调用
3. 是否有"未说出口"+"失去后才懂"+"日常器物"至少 2 个共鸣点？→ 否则不调用

## 三、选题公式

```
"______" 是 "______" 最后的 ______
```

| 填空位 | 内容 | 示例 |
|--------|------|------|
| 空 1 | 一个日常物件/痕迹 | 借书卡 / 课桌 / 毕业照 / 校服 / 同学录 |
| 空 2 | 一段从未说出口的关系 | 三年暗恋 / 那句喜欢 / 两个人的名字 |
| 空 3 | 该物件扮演的角色 | 证据 / 墓碑 / 证人 / 伪装 / 回音 / 并排 |

**必有动作：** "逆着人流往回走"式的回望时刻

**击中的底层情感：** 遗憾 / 后知后觉 / 来不及

## 四、风格必备元素

岩井俊二风格命中越多越像：
- 逆光 / 过曝 / 留白
- 慢动作 + 静默
- 日常细节放大（书本/单车/走廊/夕阳/橡皮/粉笔字）
- 主观镜头 + 特写
- 结尾的"失去后才懂"
- "逆着人流往回走"类回望动作

**可致敬的经典来源：**
- 《情书》— 借书卡 / 雪地呼喊 / 同名同姓
- 《关于莉莉周的一切》— 耳机莉莉周 / 麦田仰望
- 《花与爱丽丝》— 黄昏独舞 / 纸杯电话
- 《你好，之华》— 信箱 / 毕业册
- 《四月物语》— 樱花下单车 / 暗恋

## 五、5 个参考变体

1. **借书卡并排**：借书卡上的借阅记录是两个人名字最后的并排
2. **课桌告白**：课桌角被磨平的刻痕是三年同桌最后的告白
3. **毕业照视线**：毕业照里永远隔着的三排人是一直在看你最后的证据
4. **同学录伪装**：同学录上只写"前程似锦"的那页是"用户喜欢你"最后的伪装
5. **车站证人**：等了三年没一起走的车站是暗恋最后的证人

## 六、剧本模板（严格执行）

```markdown
# 标题（8-15 字，钩子）

## 50 秒剧本
[00-05s] 画面：...
[05-10s] 画面：...
...（精确到秒，共 8-10 个分镜）

## 旁白（1-2 句，≤30 字）
"..."

## BGM 建议（具体到 1 首歌名，不要"抒情钢琴"这种空话）
歌名 - 歌手

## 共鸣点分析（3 条，每条 1 句话）
1. ...
2. ...
3. ...

## 复刻来源
致敬《XXX》的 XX 桥段
```

### 硬约束

- ✅ 标题不烂俗（"青春不散场"/"毕业季"这种直接报废）
- ✅ 旁白克制，1-2 句点到即止
- ✅ 画面可执行（AI 视频工具能生成）
- ✅ BGM 具体到歌名
- ✅ 至少命中 2 个底层共鸣点
- ❌ 不出现"梦想"/"加油"/"未来可期"口号
- ❌ 不煽情，不堆砌情绪词

## 七、工作流

1. **确认题材/情感击中点**（1-2 个关键词）
2. **套选题公式**生成 5 个变体（每个 1 句话）
3. **选 1 个最强变体**展开 50 秒剧本
4. **按模板输出**：标题 + 分镜 + 旁白 + BGM + 共鸣点 + 复刻来源
5. **交付**，不展开额外内容

## 八、已知坑

| 坑 | 后果 | 规避 |
|----|------|------|
| 用低端模型写 | 顺从流水账，用户打回 | 用 deep thinking 模型 |
| 旁白超 30 字 | 煽情，完播率掉 | 强制 ≤30 字 |
| 标题用烂俗词 | 直接报废 | 列黑名单 |
| 缺回望动作 | 缺视觉钩子 | 强制加入 |
| BGM 写空话 | 不可执行 | 必须给歌名 |

## 九、性能基准（目标值）

- 完播率 ≥ 60%
- 点赞率 ≥ 8%
- 转发率 ≥ 3%
- 正面评论 ≥ 70%
- 单条制作时长：1-2 小时
